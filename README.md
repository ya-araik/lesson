1. Сделайте Fork репозитория через GitHub.

2. Склонируйте свой репозиторий:

git clone <ссылка-на-ваш-репозиторий>

3. Перейдите в папку проекта:

cd flexbox-practice

4. Выполните задания.

5. Добавьте изменения:

git add .

6. Создайте commit:

git commit -m "Complete header flexbox"

7. Продолжите выполнение задания.

За время работы должно быть сделано минимум 3 осмысленных commit'а.

Например:

git commit -m "Complete header flexbox"
git commit -m "Add team cards layout"
git commit -m "Complete footer and styles"

8. Отправьте работу на GitHub:

git push

9. Отправьте преподавателю ссылку на свой Fork.
